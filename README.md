<h2>Sobre o projeto</h2>

<p>O Partiu ENEM é um projeto desenvolvido por estudantes do Ensino Médio Integrado do Instituto Federal de Santa Catarina (IFSC), Campus Garopaba, para a disciplina de Projeto Integrador (PI). A proposta surgiu da ideia de criar uma plataforma gratuita que pudesse ajudar estudantes a se prepararem para o Exame Nacional do Ensino Médio, principalmente aqueles que não têm condições de pagar por cursos preparatórios ou materiais de estudo.</p>

<p>Nosso objetivo é oferecer um ambiente simples e organizado, onde qualquer pessoa possa estudar no próprio ritmo. A plataforma permitirá que o usuário faça um cadastro, acesse questões organizadas por disciplina e conteúdo, confira a correção das respostas, assista a videoaulas explicativas produzidas por professores, alunos e bolsistas do IFSC, além de realizar simulados, consultar provas anteriores e acompanhar as principais datas do ENEM.</p>

<p>Mais do que reunir conteúdos em um único lugar, queremos criar uma ferramenta que incentive a autonomia nos estudos e torne a preparação para o vestibular mais acessível. Este projeto também representa uma oportunidade de aplicar, na prática, os conhecimentos adquiridos durante nossa formação, desenvolvendo uma solução que possa ser útil para outros estudantes.</p>

</div>

<h2>Desenvolvimento</h2>

<p>O projeto está sendo construído utilizando HTML, CSS e JavaScript, com a interface inicialmente planejada no Draw.io. A identidade visual foi pensada para ser leve e intuitiva, utilizando tons de verde e um layout simples para facilitar a navegação e manter o foco no estudo.</p>
